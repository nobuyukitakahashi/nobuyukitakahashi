# 業務進行ログ：ケーブル兄弟（「いい-ch」＆「いい-NETくん」）2体ペア15秒3Dアニメーション 腕付け根の不自然な「ひれ（翼の骨格状のシワ・膜）」完全除去（Blender 5.3）

- **受付日**: 2026年11月12日
- **テーマ識別子**: `cvn_pair_anim_arm_fin_fix`
- **対象ジャンル**: `blender`
- **実行モード**: `/blender`（Blender 5.3 3Dアニメーション改修＋最終納品パッケージ化）
- **依頼内容**:
  - 最終動画において、両キャラクターの腕の付け根に「羽の骨格の翼のような不自然なひれ（リブ状の突起・膜状の引っ張りシワ）」が多数出現している問題を徹底的に解消する。
  - **【追加重点指示】足（超短足）の不自然な歪み・形崩れの解消**: 前後に足を動かす際、多少の自然な伸び縮みはあってよいが、足の元の丸い形が完全にねじれたり歪んでしまうリグ制御（`ax=0.45` 横幅カットオフや前後非対称クリフ `w_front_chest`、過剰せん断）を修正し、可愛い丸足の造形を保ったまま自然に前後スイング＆心地よく伸縮する制御に直す。
  - **【追加重点指示】ボディ本体への歪み波及防止（きめ細かい局所制御）**: 手足のリグ動作によってボディ本体（タマゴ型輪郭・お腹・胸ロゴ `LILI-ch` / `LILI-net`・顔枠）に大きな歪みが及ばないよう、腕はボディ無変形の独立剛体回転とし、足も付け根関節帯より上のボディ本体を重み `0.000` で完全保護するきめ細かい制御を入れる。
  - 実行環境は **Blender 5.3**（`C:\Program Files\Blender Foundation\Blender 5.3\blender.exe`）を使用する。
- **原因特定と解決アーキテクチャ**:
  - **原因**: 静止画用に `Body` と `Arm.L` / `Arm.R` を Boolean Union + Voxel Remesh で単一溶接メッシュ化した状態のまま、アニメーション時に腕領域の頂点のみを重み `w_arm_blend (0 -> 1)` で大角度回転（前後スイング `±46°`、手振り挙上 `+60°`）させたため、胴体側（`w=0`）と腕側（`w=1`）の境界遷移帯のポリゴンが激しくせん断・引き伸ばされ、腕の上下・前後にコウモリの翼の骨格やひれのような不自然な突起・膜が多数発生していた。
  - **解決策**:
    1. アニメーションシーンでは `Body` メッシュに腕を溶接せず、**`Body` は腕を含まない100%純粋で滑らかなタマゴ型胴体メッシュ**として保持する（これにより胴体側面に腕回転による引っ張りシワやひれが発生する可能性を幾何学的に0%にする）。
    2. **`Arm.L` / `Arm.R` は独立した滑らかな閉曲面パドルメッシュ**（根元がタマゴ型胴体内部へ深く滑らかに収まる造形）として保持し、腕メッシュ全頂点を**重み `1.000`（完全剛体 `SO(3)` 純粋回転）**でタマゴ側面の曲率中心まわりにスライド回転させる（腕自体も一切変形・せん断しないため、ひれ・折れ・シワの発生が0%になる）。
    3. 胴体と腕のマテリアルを完全同一の微細グレインマテリアルとし、腕の `visible_shadow = False`（付け根への自己影落とし防止）および根元法線の滑らかなブレンド（`DATA_TRANSFER` カスタム法線転写または接線フレア設計）を適用することで、静止時・動作時ともに継ぎ目の違和感をなくしつつ「不自然なひれ」を100%根絶する。
