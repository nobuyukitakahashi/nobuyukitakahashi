  - 参考動画：`https://www.youtube.com/watch?v=F_IKbnA7O6w`（サンリオピューロランド公式「けろけろけろっぴがステップを披露！」：超短足・丸胴体の着ぐるみマスコット特有の、小刻みな足踏みと胴体の左右ロール・上下バウンスを伴う愛らしいステップ動作）
- **アニメーション構成（15.0秒 / 24fps = 全360フレーム）**:
  1. **Phase 1（Frame 1〜132 / 0.0〜5.5秒）：間（ま）をおいて「ぴょこぴょこ」左右に体を傾けながら歩いてくる（ゴム弾性の柔軟な足元）**
     - 細かすぎる高速ステップを廃止し、1歩約13〜15フレームの間（タメ）のあるリズムで、着地時にゴムの足元が「ムニュッ」と潰れ、蹴り出しで「ぴょこっ」と伸びながら、体を左右に大きく（`±11°〜14°`）傾けて歩いてくる。
  2. **Phase 2（Frame 133〜168 / 5.5〜7.0秒）：正面構図でゴム弾性バウンスを伴ってピタッと静止**
     - 定位置（`Y = 0.0m`）に「ぴょこん、ムニュッ」と着地して弾性復帰し、正面構図に収まる。
  3. **Phase 3（Frame 169〜240 / 7.0〜10.0秒）：ゴムのように顔から下がクニュッと内側に折れ曲がる深いおじぎ**
     - 柔軟なゴム素材の体として、顔枠の下（胸元・お腹）がクニュッと内側（`+Y`）へへこみ＆縦に潰れて折れ曲がり、頭と顔全体がグッと下へ深く前傾（`40°〜45°`）しておじぎする（頭頂部が見え、地球儀も前へ大きく垂れて揺れる）。
  4. **Phase 4（Frame 241〜360 / 10.0〜15.0秒）：ゴムのようにビヨーンと伸びて元気よく手を振る**
     - 短い手がゴムのように約1.6〜1.8倍にビヨーンと伸び、肩より高い位置まで持ち上がって、ゴムのしなりを伴いながら大きくブンブンと手を振る。
