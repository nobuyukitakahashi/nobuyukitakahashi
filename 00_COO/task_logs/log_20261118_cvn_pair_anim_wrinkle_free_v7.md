## 1. 精密解析結果（v6 で手足を動かした際に発生していた微妙なしわ・たるみの4大真因）

### A. 足（超短足）動作時の「下腹部の段差・たるみ」「股間の斜めひきつれ」「アコーディオン潰れしわ」の真因
1. **水平せん断（シアー）変形によるお腹下の段差・二重あごたるみ**:
   - v6 の `deform_stubby_legs_pendulum_stretch` では、`w_sole_tilt` によって `z > 0.065m` の回転Z成分（`dy_rel * sin(rx)`）がゼロに切断されており、真の3D回転ではなく「Y方向（前後）のみの水平シアー変形」になっていた。
   - さらにピボット `z_hip`（0.135m / 0.185m）が変形上限 `z_leg_top`（0.165m / 0.245m）より下に置かれていたため、`z_hip < z < z_leg_top` の帯域で変位符号が逆転してS字に波打ち、足を後ろに引くとお腹の下がひさし状にたるみ、前に出すと胸ロゴ直下に横ジワ（くびれ段差）が発生していた。
2. **股間アーチ（`x ≈ 0`）での左右逆位相せん断による斜めひきつれしわ**:
   - `s_leg_l = 0.5 * (1 + tanh(x / 0.11))` により、股間中央（`x = 0`）の頂点にも `w_leg > 0` のまま左右逆方向の前後スイング・伸縮が加わり、歩行中に股間アーチが斜めにひきつれていた。
3. **局所Z伸縮（`stretch`）とリフト（`lift_z`）による足首の上下圧縮しわ**:
   - 足を上げた際や着地時に足先だけが `+Z` へ押し上げられ、`z_leg_top` との間が上下に最大35%押し潰されて横方向のたるみしわが発生していた。

### B. 腕（パドル手）動作時の「付け根のコブ」「ネックのくびれ折れ線」「脇下の水かきたるみ」の真因
1. **挙上ピボット `(u_flap_piv, z_flap_piv)` の位置ズレによる根元の外側抜け出し**:
   - 腕の実際の付け根高さ（いい-ch `z ≈ 0.345m` / いい-NETくん `z ≈ 0.465m`）に対し、挙上ピボットが `z = 0.705m / 0.790m`（約35cm上の目の高さ）に設定されていたため、`flap_deg = +56°` 回転時に `-dz_f * sin(alpha)` によって腕の根元が外側（`+X`）へ約25cmも引き抜かれ、胴体内部用の細い茎部分が露出してコブや長い水かきたるみを生んでいた。
2. **`W_eff = d_neck_out + W_k` による吸盤スカート幅の暴走拡大**:
   - 腕を傾けた鋭角側で `d_neck_out` が10〜15cmに達し、スカートリムが顔枠横や胸・背中まで広くスライドして巨大なテント状のたるみ皮膜を形成していた。
3. **ベジェスカート＋カラー遷移帯＋剛体先端の3段つぎはぎによる変曲点（ネックのくびれしわ）**:
   - 区分的に異なる数式で生成した3領域を `vstack` していたため、接続部（`j ≈ n_skirt`）に曲率変曲点（凹みしわ）が残っていた。
4. **カスタム法線の `np.maximum` 折れ線クランプによる陰影スジ**:
   - 法線Z成分に非微分な `np.maximum` を用いていたため、スカート途中にシェーディングの暗いリング状スジが発生していた。
