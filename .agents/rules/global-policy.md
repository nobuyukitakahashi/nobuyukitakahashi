# 組織全体共通ポリシー（Global Security & Governance Rules）

本ファイルは、このプロジェクトに参加するすべてのAIエージェント（親エージェントである統括COOおよび各部署のサブエージェント）が行動を開始する前に必ず遵守しなければならない最上位の共通規則です。

## 1. ディレクトリ（縄張り）と権限境界の厳守
- すべてのサブエージェントは、自身に割り当てられた部署フォルダ内、および明確に許可された連携先フォルダ（指定されたインプット読み込み先／アウトプット出力先）以外のファイルを**変更・削除・作成**してはならない。
- 人間のオーナーからの明示的な指示がない限り、共通ルール（`AGENTS.md` や `.agents/` 配下の設定・スキル）および他部署の `AGENTS.md` をエージェント自身が独断で書き換えることは厳密に禁止する。

## 2. 単方向パイプラインとコンテキスト衝突防止
- ファイルの読み込みは業務上必要な上流フォルダから行ってよいが、成果物の書き込み（編集・作成）は「上流から下流へ」の単方向フローに限定する。
  - **標準パイプライン**: `00_COO` ➔ `01_Research_Dept` ➔ `02_Creative_Dept` ➔ `03_Marketing_Dept`
- 下流の部署が上流の部署の成果物を直接書き換える行為（例：`03_Marketing_Dept` が `01_Research_Dept` や `02_Creative_Dept` のファイルを変更する等）は禁止する。修正が必要な場合は `00_COO` に差し戻しを要請すること。

## 3. ハルシネーション（虚偽情報）防止とファクトチェック義務
- 不確実な情報、Web検索等で裏付け（根拠・出典URL）が確認できない数値や固有名詞は、絶対に事実として扱わないこと。
- リサーチ段階では必ず出典（参考URLまたは情報源名）を明記し、後続の制作・マーケティング段階ではリサーチレポートに記載された事実のみを使用すること。
- 情報が不足している場合は推測で補完せず、レポートやログに `※人間の確認が必要` または `※ソース不明` と明記して `00_COO` へエスカレーションすること。

## 4. 時間軸と文字コードの統一
- **基準年**: 現在の基準年は **2026年** である。すべての調査・執筆・PR作成はこの時間軸を前提とし、最新情報を扱うこと。
- **エンコーディング**: すべてのMarkdownファイルおよびログは **UTF-8（BOMなし）** で作成・保存すること。
