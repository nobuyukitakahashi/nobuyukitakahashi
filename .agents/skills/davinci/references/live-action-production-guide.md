# DaVinci Resolve 実写編集・議会テロップ・5段DSP整音・無音動画同期ガイド

実写映像・会議/議会収録・無音欠落動画の音声同期を DaVinci Resolve Studio 21.2 で放送品質に仕上げる専門リファレンス。

## 1. 前後不要区間の精密トリミング（映像 × 音声ハイブリッド解析）
- 冒頭の床映り・構え直し・急パン・AF迷いや、末尾の姿勢戻し・録画停止ボタン音（スパイク）を除外するため、0.17〜0.5秒間隔のコンタクトシート目視監査と音声 RMS (dBFS) 解析を併用し、`startFrame` / `endFrame` をフレーム単位で特定する。
- `mediaPool.AppendToTimeline([{"mediaPoolItem": clip, "startFrame": in_frame, "endFrame": out_frame}])` でクリーンなサブクリップを配置。

## 2. セクション分割スタビライズ（過度なクロップ防止）
- 移動パン区間と定点手持ち区間が混在する場合、**クリップ全体への一括 `TimelineItem.Stabilize()` は禁止**（極端なズームイン・見切れが発生）。
- フレーム連続（欠損・重複ゼロ）でサブクリップ分割し、**定点手持ちセクションの `TimelineItem` にのみ個別に `item.Stabilize()`** を適用する。

## 3. 区間別 `TimelineItem.SetCDL()` 露出・色味統一
- 各セクションの平均輝度（Y）とRGBバランスを計測し、`item.SetCDL({"NodeIndex": "1", "Slope": "R G B", "Offset": "R G B", "Power": "R G B", "Saturation": "S"})` で適用。
- 暗転区間は `Power` を `0.56〜0.68` へ下げ中間調を持ち上げつつ Blue を微調整。
- **暗所・逆光議場（平均輝度 `Y ≈ 85〜89`）の大幅ブースト例**: `Slope: "1.38 1.36 1.32"`, `Offset: "0.04 0.04 0.05"`, `Power: "0.65 0.65 0.65"`, `Saturation: "1.14"` で `Y ≈ 134〜138`（`+55〜57%` 向上）へ改善。

## 4. `V2` 透過PNG テロップ・発言者ネームプレート合成 ＋ `.srt`
1. **短尺映像（数分程度）**: ユニーク状態ごとの透過PNGを全フレーム分のハードリンク連番（`telop_0000.png`〜）として Media Pool へ1本インポートし、`V2`（`trackIndex: 2, mediaType: 1`）へ配置。
2. **長尺議会・会議映像（1時間超・数十〜百区間）**:
   - **ASR誤変換の100%校正**: 公式議員名簿（選出市町村・役職・委員会）・会議次第と全発言者を照合して同音誤変換を完全修正する。
   - **区間別 32bit RGBA 透過PNG配置**: 発言区間ごとの `1920×1080` 透過ネームプレート（役割別カラーバッジ＋肩書き＋氏名＋テーマ）を `mediaPool.AppendToTimeline([{"mediaPoolItem": png_clip, "startFrame": 0, "endFrame": dur, "mediaType": 1, "trackIndex": 2, "recordFrame": timeline_start_frame}])` で `V2` の正確なタイムコードへ配置する。

## 5. 実写音声 5段DSPノイズ軽減 ＆ 音量ブースト（48kHz / 16-bit Stereo WAV ➔ `A1`）
ロボット声（ミュージカルノイズ）や音割れを防ぎつつ発話を明瞭化する標準パイプライン：
1. **HPF (`100 Hz`) ＋ LPF (`11 kHz`)**: 空調ランブル・振動・高域ヒス除去。
2. **STFT ソフト・スペクトルゲート（Floor `0.45`＝最大 `-6.9 dB` 減衰＋時間/周波数平滑化）**: 定常背景ノイズを自然に抑制。
3. **明瞭度EQ（`2.3 kHz` 中心 `+2.4 dB`）**: 日本語子音・輪郭を明瞭化。
4. **ソフトニー・コンプレッサー（Threshold `-18.5 dBFS`, Ratio `2.8:1`, Makeup `+7.8 dB`）＋静寂部ソフトエクスパンダー**: 発話平均RMSを約 `-20.3 ➔ -14.6 dBFS`（`+5.6 dB`、SN比 `+4.8 dB`）へ均一化。
5. **True-Peak リミッター（`-1.00 dBFS` シーリング）**: 拍手・紙めくり音のクリッピングを100%防止。

## 6. 無音欠落動画 × 別録りICレコーダー音声（MP3/M4A）の2段階高精度同期
1. **部分有音動画（音響エンベロープ相互相関）**:
   - 動画有音部と別録り音声の振幅エンベロープ（10Hz粗探索 ➔ 100Hz精密探索）で正規化相互相関を計算し、`r > 0.90` でミリ秒/フレーム単位のオフセットを特定。1時間超は冒頭・中盤・終盤でクロックドリフトを検証。
   - 全編別録り統一版と、無音部のみ補完するハイブリッド版を構築可能。
2. **完全無音動画（`mvhd` クロック差分 × 視覚ランドマーク照合）**:
   - 同一カメラの別動画との QuickTime `mvhd` `creation_time` 差分およびICレコーダー側 `.m4a` `mvhd` 差分から初期オフセットを逆算。
   - 起立・一礼・着席等の視覚ランドマークフレームと音声発声・返礼・着席音を照合して1フレーム精度の `startFrame` を確定。
