# Blender マスコットキャラクター造形・3Dアニメーション（v7/v8）＆ 同期SE生成ガイド

丸胴体・超短足・超短腕マスコット（カービィ／サンリオ型等）や一体成型キャラクターを Blender 5.2 / 5.3 で破綻ゼロに造形・アニメーションさせる際の専門リファレンス。

## 1. 静止画 vs アニメーションでの同色パーツ（胴体と腕等）構造の使い分け
- **静止画単体造形時**:
  - `BOOLEAN (UNION)` ＋ 高解像度 `REMESH (VOXEL)` ＋ 正面2D外周シルエットロック付き2段階調和スムージング（`Smooth_Seam_3D` + `Smooth_Seam_Y`）で境界筋を完全除去する。
- **アニメーション時（独立腕メッシュの完全シームレス一体化）**:
  - 静止画用の単一溶接メッシュを局所ウェイトで大角度回転させると「翼の骨格・ひれ状のシワ」が発生し、閉曲面同士の単純交差では境界にV字角の陰影線が残る。
  - **①ボディ本体（`Body`）**: 腕なしの純粋滑らかメッシュとして無変形保護（胴体ひれ0%）。
  - **②腕（開放リム型構造化メッシュ）**: 全フレームでトポロジ固定（フリッカーゼロ）とし、先端〜中間は純粋剛体 `SO(3)` 回転させる。
  - **③根元スカート部**: 毎フレームのボディ表面へ2次ベジェ曲線（$\mathbf{B}_0 \to \mathbf{B}_1 \to \mathbf{B}_2$）で滑らかにR架橋（脇下はタイトにしてひれを防止）。
  - **④カスタム法線一致**: `normals_split_custom_set_from_vertices` でリム端法線をボディ変形後法線と角度差 `0.00°` で完全一致させ、同一マテリアル・`visible_shadow=False` とする。

## 2. 丸胴体・超短足・超短腕マスコットのアニメーション鉄則（v7/v8）
1. **純粋剛体回転の原則**: 短い腕や足をゴムのように過度に引き伸ばす表現やおじぎで腹部を凹ませる表現は厳禁とし、タマゴ／球体側面の接線曲率中心まわりの `SO(3)` 純粋剛体回転（`det(R)=1`, 伸縮率 `1.000倍`）で短いパドル手をほっぺ横まで挙上・前後スイングさせる。
2. **腕（独立開放リム型パドルメッシュ）のしわ・コブ・肩上端影スジゼロ化**:
   - 上下挙上（Flap）および前後スイング（Swing）の回転ピボットは必ず**実際の腕付け根断面中心（肩ボールジョイント中心）**に配置する。高い位置で手を振る際は、肩ピボット自体を**タマゴ型胴体表面の水平断面等高線 `R_surf(z)` に厳密追従させながら子午線に沿って滑らかにリフト**させつつ回転させ、高挙上時の肩上端影スジを完全消滅させる。
   - 腕パドルの先端〜中間の丸みを潰す原因となる **`dR_from_c` クランプは全面廃止**し、先端側 `m_lock = 0.55` 領域を純粋剛体として保護する。
   - `d_neck_out` のような動的暴走オフセットは禁止し、交差ループすぐ外側のコンパクトなフィレット幅にリムを密着させ、**単一 $C^2$ 母線補間＋境界固定2D調和ラプラシアン緩和**でネックのくびれ折れ線をゼロにする。
   - カスタム法線ブレンドでは `np.maximum` 等の非微分クランプ関数を禁止し、リム端（角度差 `0.00°`）から外側へ純粋な $C^2$ `smootherstep` と2Dガウシアンフィルタで遷移させて陰影リングスジを防ぐ。
3. **超短足の形崩れ・股間斜めひきつれ防止とボディ完全保護（`w=0.000` ロック・`z_crotch` 基準ドーム変形）**:
   - 足の前後スイング時は足キャップ外縁まで均一ウェイト `w=1.000` とし、**股間分岐高さ `z_crotch` 基準のドーム変形**で股関節リング帯のみ `1.0 -> 0.0` へ滑らかに減衰させ、それより上のボディ本体・お腹・胸ロゴ・顔枠領域は厳密に `w=0.000` ロックする。
   - Phase 1 歩き出しは約 `33°〜36°` の斜め前3/4アングルから正面構図へ回り込み、正面で手を振る区間（Wave）では**両足を対称シルエット（接地・平行）に保持**して片足上げによる股間・下腹部の非対称歪みを防ぐ。
   - 足の回転ピボット高さ `z_hip_piv` は必ず変形上限 `z_leg_top` に一致させ、`z < z_leg_top` 全域で `dz = z - z_leg_top <= 0` を単調維持して胸ロゴ直下のS字波打ちを根絶する。
   - 股間アーチ中央（`x ≈ 0`）へ中立減衰マスクを適用し、変形後の `Body` 下部遷移帯に対して頂点座標 $\mathbf{p}$ ではなく**変位ベクトル場 $\Delta\mathbf{p} = \mathbf{p} - \mathbf{p}_{\text{rest}}$ に対する境界固定ラプラシアン調和緩和**を適用し、静止時痩せゼロ（誤差 `0.0000mm`）と動作時しわゼロを両立させる。
4. **おじぎ時の床接地ロック**: 足底〜足首下部の回転重みを抑えて短い2本の足を床に踏ん張らせ、毎フレーム足底最下点 `min(z)` で床面接地を厳密ロックする。

## 3. 数式タイムライン完全同期の 48kHz ステレオ効果音（SE）＆ Blender VSE AAC 統合
- アニメーション制御スクリプト内の位相・フレーム数式（歩行ステップ接地、着地バウンス、手振り周期、おじぎ等）からミリ秒精度で同期した **48kHz 16bit ステレオ WAV** をプログラム生成する。
- Blender VSE（`scene.sequence_editor_create()` ➔ `sequences.new_sound()`）に配置し、`scene.render.ffmpeg.audio_codec = 'AAC'`（`audio_bitrate = 192`, `audio_mixrate = 48000`）で映像と完全同期した音声付き MP4 として直接書き出す。
