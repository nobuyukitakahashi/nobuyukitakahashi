## 2. v5 全面改修の技術要点（オーナー指摘3項目の100%根絶）

### A. 腕の付け根の「不自然なひれ（羽の骨格・翼状の膜）」の100%根絶
- **真因**: 旧版では胴体（`Body`）と両腕（`Arm.L`, `Arm.R`）を Boolean Union + Voxel Remesh で単一溶接メッシュに統合した上で局所重み `w_arm_blend (0.0 -> 1.0)` により腕を回転させていたため、大きく動く腕頂点と動かない胴体側面頂点の間の遷移帯が30〜50cm引き伸ばされ、脇の下や肩の上にコウモリの翼や魚のヒレのような鋭い筋・膜が出現していた。
- **解決アーキテクチャ**:
  1. **純粋タマゴ型胴体メッシュ（`fuse_arms=False`）**: アニメーション用の `IICh_Body` / `IINet_Body` は腕を含まない100%純粋で滑らかなタマゴ型胴体＋超短足メッシュとして生成。これにより、腕がどの角度に動いても**胴体側面のメッシュは1ミリも引っ張られず（歪み波及 0.000%）、胴体側に「ひれ」や「シワ」が出ることは幾何学的に100%不可能**となった。
  2. **独立した閉曲面パドル腕（`IICh_Arm.L/R`, `IINet_Arm.L/R`）の完全剛体 `SO(3)` 回転**: 根元フランジ（`root_flare_gain = 0.0`）を排したぷっくり丸いティアドロップ閉曲面として腕を生成し、内側根元をタマゴ胴体内部（8〜10cm）へ深く滑らかに埋め込んだ上で、全頂点一律 **`w = 1.000` の純粋剛体 `SO(3)` 回転**（タマゴ胴体の曲率中心 `(u_flap_piv, y_sh, z_flap_piv)` まわり）で駆動。`visible_shadow = False` かつ胴体と完全同一の微細グレインマテリアルにより、静止時も動作中も継ぎ目やひれが一切出ないカービィ型パドル手を実現。

### B. 足（超短足）の不自然なねじれ・カギ鼻状変形の完全解消と心地よい弾性伸縮
- **真因**: 旧版の横幅カットオフ `u_leg_x_out (ax = 0.45m)` が足の外側半分を切断して内側半分だけを動かしていたこと、および前後非対称クリフ `w_front_chest` と過大並進せん断の三重掛けにより、足がねじれたりカギ鼻状に潰れていた。
- **解決アーキテクチャ**:
  1. **横幅カットオフ（`u_leg_x_out`）と前後非対称クリフ（`w_front_chest`）の完全撤廃**: 足先〜足首下部（`IICh: z <= 0.085m`, `IINet: z <= 0.130m`）は足の外縁まで均一に **`w_leg = 1.000`** とし、足の丸い塊全体が一体として動くよう刷新。
  2. **足の付け根支点（`z_hip_piv = 0.145m / 0.215m`）まわりの素直な振り子回転（`±19°〜20.5°`）＋ 心地よい縦弾性伸縮（`+8.5%` 伸び ／ `-6.0%` クッション縮み）**: 符号反転ピボットや過剰な水平せん断を廃止し、足の軸方向に沿ってぷっくり気持ちよく伸び縮み（体積保存つき）しながら前後にトコトコ振る自然なマスコット歩行を実現。

### C. 手足リグから「ボディ本体（お腹・胸ロゴ・タマゴ輪郭）」への歪み波及ゼロ保証
- **3D楕円体ソケット（股関節局所フォールオフ）制御**:
  - 足の付け根の関節リング帯（`IICh: z = 0.085m -> 0.165m`, `IINet: z = 0.130m -> 0.255m`）で `smootherstep` により重みを `1.0 -> 0.0` へ滑らかに減衰させ、胸ロゴ下端より上（`IICh: z >= 0.165m`, `IINet: z >= 0.255m`）のボディ本体全域は **厳密に `w_leg = 0.000`（完全無変形）** にロック。
  - おじぎ時も上部ボディと胸ロゴは `u_bow = 1.000` の完全剛体回転とし、全体バウンス `squash_z` も `±1.5%` 以内に抑えることで、**全360フレームを通じてボディ本体のタマゴ型シルエット・お腹・胸ロゴ（`LILI-ch` / `LILI-net`）に歪みが一切波及しない**きめ細かい制御を実現。
