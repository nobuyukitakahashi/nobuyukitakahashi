# 3Dモデリング＆レンダリング設計ドラフト：株式会社CVN「いい-NETくん（LILI-net）」

## 1. 5面図のピクセル計測値と3D座標系定義
参照5面図（`05_front.png`, `03_side.png`, `01_back.png`, `04_top.png`, `02_bottom.png`）を解析した結果、正面図・背面図・側面図はすべて高さ `1024 px` で垂直スケールが完全一致していることを確認した。
Blender空間における基準スケールを `400 px = 1.000 m`、足底（`y_px = 1022`）を `Z = 0.000 m` と定義する：

- **座標変換式**:
  - `X = (x_front - 393.5) / 400.0` （左右軸：正面から見て右が `+X = Left side`、左が `-X = Right side`）
  - `Y = (x_side - 342.5) / 400.0` （前後軸：前面が `-Y`、背面が `+Y`）
  - `Z = (1022.0 - y_px) / 400.0` （上下軸：足底が `0.000 m`、頭頂が `2.010 m`、地球儀中心が `2.370 m`）

## 2. 各パーツの3D造形・5面図整合性補正仕様

### (1) ボディ＆二股の丸足（`Body`）
- **形状特性**:
  - 最大幅位置は `y_px = 560`（`Z = 1.155 m`）、正面半幅 `W_max = 0.916 m`（`366.5 px`）、側面半奥行 `D_max = 0.855 m`（`342.0 px`）。
  - 下部中央（`X = 0`）は `y_px = 963`（`Z = 0.147 m`）を頂点とする滑らかな逆V字／U字の股下アーチを描き、左右の丸足先端（`X = ±0.2588 m`, `Z = 0.000 m`）へと繋がる。
- **正面・側面の両立設計**:
  - 脚の中心線（`X = ±0.2588 m`）に沿った前後プロファイル `(Y, Z)` を側面図（`03_side.png`）の卵型下部輪郭 `Z_side(Y)` に一致させ、中央部（`|X| < 0.2588 m`）を正面図（`05_front.png`）の股下曲線 `Z_bot_front(X)` に沿って滑らかに持ち上げる3D曲面として造形する。
  - これにより、正面・背面視では可愛い二股の丸足シルエット、側面視ではぷっくりと丸い卵型シルエット、斜め3/4視および底面視では立体的な2本の丸足パッドが破綻なく両立する。

### (2) フェイスフレーム（`Face_Frame`）・スクリーン（`Face_Screen`）・目（`Eye.L/R`）・口（`Mouth`）
- **形状特性**:
  - 青い太枠フレーム（`#3C5AAA`, 幅 `42.5 px = 0.106 m`）およびクリームイエローのフェイススクリーン（`#FAE6AA`）を、ボディ前面曲面 `(X, Y_body(X, Z), Z)` に完全密着（コンフォーマル投影）させた立体ラバーベゼル＆スクリーンとして生成する。
  - 左右の丸目（`#3250AA`, 中心 `X = ±0.310 m, Z = 1.251 m`, 半径 `0.0625 m`）とU字スマイル口（`#3250AA`, 円弧半径 `0.4625 m`, 線径 `0.0625 m`）も同様に前面曲面へ密着配置する。

### (3) 胸元ロゴ `LILI-net`（`Logo_Decal`）
- `05_front.png` の胸元領域（`x = 190..630, y = 815..915`）から黄色文字（`#FFFF00`）＋黒フチ（`#000000`）を正確に抽出し、背景ピンク色（`#F050A0`）を完全透過処理＆4倍高解像度化したデカールテクスチャ `02_Creative_Dept/drafts/lili_net_logo_decal.png` を生成する。
- ボディ前面の胸元曲面（`Z = 0.27..0.52 m`）に歪みなくコンフォーマル配置し、正面図・側面図（右胸側の `net` の回り込み）双方と完全一致させる。

### (4) 左右の柔軟ラバーアーム（`Arm.L`, `Arm.R`）
- 正面図の「ハの字」広がり角度（`Z = 0.29..0.67 m`, 先端 `|X| = 0.984 m`）と、側面図の丸みのあるティアドロップ／パドル形状（前後幅 `0.362 m`）を統合した3Dラバーアームとして造形する。
- カラーは側面図・上面図・底面図に準拠した少し濃いローズピンク（`#E83F96`）を採用し、ボディとの立体的なコントラストを高める。

### (5) 背面S字アンテナ（`Antenna`）＆頭上の地球儀（`Globe`）
- **S字パイプ**: 側面図（`03_side.png`）から抽出した中心軌道に従い、背中下部（`Z = 0.60 m, Y = +0.75 m`）から出発して後方へ膨らみ（`Z = 1.05 m, Y = +1.101 m`）、背中に沿って前方へカーブしながら立ち上がり（`Z = 2.08 m, Y = +0.925 m`）、頭頂部上方（`Z = 2.35 m`）で地球儀前面側へ接続する半径 `0.051 m` の滑らかな3Dチューブとして造形する。
- **地球儀**: 中心 `(0, 1.265, 2.370)`、半径 `0.181 m` の球体とし、`05_front.png` から抽出した水色の海（`#14C8EF`）と緑の大陸（`#009933`）を球面マッピングした高解像度テクスチャ `02_Creative_Dept/drafts/globe_texture.png` を適用する。

## 3. アーマチュア（リグ）＆マテリアル・レンダリング設計
- **ボーン構成**: `Root` ➔ `Body` ➔ `Leg.L`, `Leg.R`, `Arm.L`, `Arm.R`, `Antenna_1` ➔ `Antenna_2` ➔ `Antenna_3` ➔ `Globe`
- **質感設定**: カラーマネジメント `Standard`、Principled BSDF（`Roughness = 0.25`, `Coat Weight = 0.40`, `Subsurface Weight = 0.08`）＋ Freestyle輪郭線により、アニメ調の鮮やかな発色とソフトシリコーン／ソフビの弾力あるツヤ感を両立させる。
