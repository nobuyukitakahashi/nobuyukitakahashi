# 制作仕様書：いい-Net光 公式ロゴ（.ai）のSVG変換＆Blender 3DベベルCGレンダリング
- **制作日**: 2026年11月2日
- **担当部門**: `02_Creative_Dept`（Blender MCP `blender` 連携）
- **使用エンジン**: Blender 5.2.3 LTS / Cycles GPU (OptiX, 256 samples, WQHD 2560x1440, AgX High Contrast)

## 1. ベクター抽出・SVG変換仕様
- **元データ**: `いい-Net_logo_official.ai`（CorelDRAW 2026 出力 / Illustrator v15 Private Data `AIPrivateData2` 圧縮PostScriptストリーム格納形式）
- **構成パス（全9オブジェクト）**:
  - ロイヤルブルー（CMYK `C:95 M:85 Y:0 K:0`）：`ii_1_left`, `ii_1_right`, `ii_2_left`, `ii_2_right`, `hyphen`, `char_N`, `char_E`, `char_T`（計8シェイプ）
  - ゴールドイエロー（CMYK `C:0 M:0 Y:100 K:0`）：`hikari_kanji`（「光」＋右下の4芒星スパークルの複合パス `*u ... *U`）

## 2. Blender 3Dモデリング＆ベベル設計
- **スケールと配置**: ロゴ全幅を `8.0m`（X: `-4.0m` 〜 `+4.0m`）、押し出し奥行きを `0.42m`〜`0.44m` に正規化し、ダークオブシディアン（黒曜石）の反射フロア上に配置。
- **ベベル＆法線設計**:
  - 表面（Slot 0）の完全な平面性を維持しつつ、外周エッジ（Slot 1）に多段ラウンドベベルと `Weighted Normal (keep_sharp=True)` を適用。
  - 「光」の鋭角部（ハネ・スパークル内角）におけるベベル自己交差を防ぐため、ベジェ曲線上の微小重複制御点を事前除去した上で高精度ラウンドベベルを生成。

## 3. デュアルマテリアル＆スタジオライティング設計
- **「いい-NET」ブルー（2スロット構成）**:
  - 正面フラット面（`IINet_RoyalBlue_Metal`）：深みのあるサファイア・ロイヤルブルーのサテン・アノダイズドメタル。
  - ベベルエッジ＆側面（`IINet_Blue_BevelRim`）：高反射プラチナ・シアンブルーの鏡面クリアコート仕上げ。
- **「光」ゴールド（2スロット構成）**:
  - 正面フラット面（`IINet_Hikari_Gold`）：重厚感のある24Kリッチゴールド。
  - ベベルエッジ＆側面（`IINet_Gold_BevelRim`）：シャンパンゴールドのハイスペキュラー鏡面リム仕上げ。
- **6灯スタジオライティング＆正面85mmカメラ**:
  - トップベベル専用ストリップライト、左右からのシアン／ゴールドの斜めリムライト、ボトムベベル用のローアングルリム、および背景ウォールへのロイヤルブルー・ハローライトを配置し、85mm望遠スタジオカメラで歪みのない正面ヒーローショットを撮影。
