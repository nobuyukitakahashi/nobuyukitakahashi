### 2. 全面再設計の技術要点（旧ラバー弾性表現の完全廃止 ＆ カービィ型 `SO(3)` 純粋回転リグ）

オーナーからのフィードバック（「ラバー弾性アニメの不自然な伸縮・お腹凹みを全廃し、`Kirby walk cycle (24fps)` お手本のような超短足キャラクターの可愛い仕草に全面再設計する」）およびCOO視覚監査フィードバックに基づき、変形エンジンと全4フェーズの演出を再構築・ブラッシュアップしました。

#### A. 旧ラバー変形の廃止項目（100%ゼロ化）
1. **腕の伸縮（旧 `1.85倍`）の完全廃止**: 短いパドル手の長さ・丸みは全360フレームを通じて常時 **`1.000倍`（伸縮ゼロ）** を厳守。
2. **おじぎ時の腹部凹み・くびれ（旧 `-26%`）の完全廃止**: タマゴ型ボディは常時ぷっくり滑らかなソフビ／カービィ体型を維持し、胸ロゴ（`LILI-ch` / `LILI-net`）の歪み・潰れを完全ゼロ化。
3. **足のゴム伸縮（旧 `-24%〜+28%`）と泥酔的な大傾き（旧 `±12°`）の廃止**: 胴体のクッション伸縮は着地時のごく自然な **`±2.4%〜3.0%`** 以内に限定し、歩行時のロール傾きも可愛い **`±3.8°`** に抑制。
4. **遠すぎる開始位置（旧 `Y = +11.5m`）の廃止**: 開始位置を **`Y = +4.35m`**（1歩あたり約 **`0.272m`** の等速自然な歩幅）に設定し、Frame 1 から可愛い表情と短い手足の動きが鮮明に見えるよう刷新。

#### B. 破綻ゼロ・ぷっくり造形100%維持の `SO(3)` 純粋回転リグ
- **短いパドル手のタマゴ側面接線曲率ピボット `SO(3)` 純粋直交回転**:
  - 各キャラクターのタマゴ型側面曲率中心（`IICh: (0.295, 0.715)`, `IINet: (0.455, 0.800)`）まわりの上下パタパタ挙上回転（Flap）と、肩関節まわりの前後スイング回転（Azimuth）を `det(R) = 1.000` の純粋直交回転として合成。
  - パドル突出領域全域でブレンド重み `w_arm_blend = 1.000` を保証することで、両キャラクターとも外側の短いパドル手がほっぺの横・目線高さ（`+57.5°〜+59.5°`）まで大きく上向きにせり上がってもL字折れ・脇ノッチ・胴体めり込み・体積収縮が一切発生せず、丸く短いカービィ手がそのまま元気よくパタパタ振れる。
- **超短足の大きな前後ストライド＆つま先キュッ上向き＆後ろ足蹴り上げ機構**:
  - 股下中央の滑らかな左右分離重み `0.5 * (1 ± tanh(x / 0.085))` と、前すね／後かかと適応ピボット `y_piv = 0.245 * tanh(rx / 0.24)` により、大きな前後ストライド（`0.148m / 0.164m`）とつま先アップ（`32.5° / 34.0°`）・後ろ足蹴り上げ（`+5.8cm / +6.6cm`）でも胸ロゴ直下の横シワや股下引き裂きを100%防止（`dz'/dz > 0` 完全保証）。
- **両足しっかり踏ん張り型のおじぎピボット機構**:
  - 足底〜足首下部（`z <= 0.036m / 0.048m`）の回転重みを `0.08` に抑えて床にしっかり踏ん張らせ、前面足首ピボット（`y_bow_piv = -0.345m / -0.285m`, `z_bow_piv = 0.155m / 0.220m`）まわりに上部ボディ＆胸ロゴ（`u_bow = 1.000` 完全剛体）を `20.5° / 21.5°` 回転させることで、正面からも**短い2本の足の上に胸ロゴと丸い身体が綺麗に見えたままペコリとおじぎする**可愛いシルエットを実現。
- **足底最下点 `min(z)` による厳密接地ロック**:
  - 毎フレーム変形後の `Body` 最下点 `z_min` を解析計測して `arm_obj.location.z` にフィードバックすることで、全360フレームで床面 `Z = 0.0m` へのめり込みゼロ・不自然な浮きゼロを実現。静止フレーム（`Frame 156〜168`, `Frame 360`）では変形量 `0` となり、`build_pair_scene.py` の完成静止画（IoU `98.11%`）と100%完全一致。

## Part 3. リファレンス解析サマリー＆設計根拠
- **動作リファレンス出典**: `Kirby walk cycle coloured`（`https://www.youtube.com/watch?v=xZMflRnbC3o`、24fps フレーム単位解析）
- **ペア造形・正面バランス基準**: 株式会社CVN 公式キャラクター「ケーブル兄弟（いい-ch ＆ いい-NETくん）」2体横並び原画 `ref_20261110_pair_balance.png`（完成静止画シルエット重なり一致率 **IoU 98.11%**）
- **24fps リファレンス解析による4大設計原則**:
  1. **周期・テンポ**: 1歩＝8フレーム（左右1サイクル＝16フレーム＝0.67秒 @ 24fps）の軽快で愛らしい「トコトコ／ポテポテ」ステップ。
  2. **丸胴体のシルエット保持**: 胴体をグニャグニャ潰したりくびれさせたりせず、ぷっくり丸いソフビ／マスコット体型（着地クッションの体積変化 `±2.4%〜3.0%` 以内）を常時維持し、胸ロゴ（`LILI-ch` / `LILI-net`）の歪みをゼロに保つ。
  3. **超短足の可愛い足運び**: 足をゴムのように伸縮させるのではなく、短い足が丸いお尻・お腹の下を前後（`-Y` 前方つま先アップ着地 ⇔ `+Y` 後方蹴り上げ）へ回転スイングし、1歩ごとに身体が軽く上下バウンス＆逆位相でわずかにツイストする。
  4. **超短腕（パドル手）の可愛い仕草**: 腕の引き伸ばしを完全廃止（`stretch = 1.000` 固定）。ぷっくり短いパドル型のまま、歩行時は足と逆位相で前後にパタパタ振り、おじぎ時は両足を床に踏ん張って丸い身体ごと「ペコリ」と前傾して短い手をちょこんと後ろへ添え、手振り時は両キャラとも外側の短い手をほっぺ横・目線上の高い位置まで一生懸命持ち上げて「パタパタ！」と振りながら小首（身体）を傾げて片足を交互にちょこんと浮かせる。
